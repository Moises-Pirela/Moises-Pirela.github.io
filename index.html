GameAsset

Unity scenes shouldn't be Git's problem.

Unity scenes and prefabs are serialized YAML, which makes them miserable to diff, merge, and review through normal Git workflows. GameAsset is a local desktop tool that parses Unity assets into a real semantic representation, automatically merges the changes that are safe to merge, and shows you a clear visual decision for every genuine conflict, no manual YAML surgery required.

  • Semantic three-way merge with a full audit trail
  • Launches automatically the moment Git hits a Unity conflict
  • Visual conflict resolution, no hand-edited YAML
  • 100% local: no cloud account, no uploaded project data
